# Shot Splitter — 长视频提示词镜头精细化拆分

## Activation

当用户提到"拆分提示词"、"分镜拆分"、"镜头拆分"、"精细化提示词"、"拆分长视频"时自动激活。也可通过 `/shot-splitter` 手动触发。

## Workflow

### Phase 0: 选择源文件

1. 向用户确认要拆分的长视频提示词文件路径。

> 你好！我是长视频提示词镜头拆分工具。请提供要拆分的长视频提示词文件路径（如 `prompts/xxx/场景一-厨房遭遇战.md`）。

2. 读取该文件，解析其六段式结构（或用户自定义的提示词结构），提取以下核心要素：

| 提取要素 | 来源段落 | 用途 |
|---------|---------|------|
| 美学风格与渲染参数 | Section 1 | 填入每个镜头的「氛围与画质规范」 |
| 角色设定（外观/材质/状态） | Section 2 | 填入每个镜头的「角色设定」 |
| 环境与光影 | Section 3 | 填入每个镜头的「场景设定」 |
| 物理与特效 | Section 4 | 按镜头分配到对应「画面内容」 |
| 运镜设计 | Section 5 | 填入每个镜头的「运镜手法」 |
| 动作时间线（核心拆分依据） | Section 6 | 拆分为独立镜头的主要依据 |

3. 如果文件结构不符合预期，向用户确认后按实际内容解析。

### Phase 1: 分析与拆分规划

#### 1.1 拆分原则

基于 Section 6（动作时间线）的节拍（beats），按以下规则拆分为独立镜头：

**拆分触发条件**（满足任一即拆为新镜头）：

| 条件 | 说明 |
|------|------|
| 景别变化 | 相邻节拍的景别发生显著变化（如 Medium → Extreme Close-Up） |
| 运镜切换 | 相邻节拍的运镜方式不同（如 Steadicam → Handheld） |
| 情绪标签变化 | 节拍的情绪标签类别不同（铺垫/预警/觉醒/爆发/高潮/追逐/收束/余波） |
| 场景空间切换 | 动作发生的主要空间位置改变（如台面 → 地面 → 画面外） |
| 视角主体切换 | 镜头跟随的主体改变（如跟随猫 → 跟随机器人） |

**合并保护**（以下情况倾向合并为同一镜头）：

| 条件 | 说明 |
|------|------|
| 连续动作 | 同一个持续动作的自然延续（如"举枪瞄准 → 开枪"属于一个连续动作） |
| 慢动作回放 | 签名镜头的慢动作回放节拍与其正常速度节拍**必须合并**为同一镜头文件，在「画面内容」中用"正常速度描述 + 慢动作描述"的分层结构呈现 |
| 极短节拍 | 时长 ≤ 1 秒的节拍，如果与相邻节拍属于同一连续动作，合并处理 |

#### 1.2 展示拆分方案

将拆分方案展示给用户确认：

```
📋 拆分方案（共 N 个镜头）：

镜头 1「[名称]」 — [时间范围] — [景别] · [运镜] — [情绪标签]
镜头 2「[名称]」 — [时间范围] — [景别] · [运镜] — [情绪标签]
...

输出目录：[原目录]/[原文件名去掉.md]拆分/
```

请用户确认或调整。用户可以：
- 合并某些镜头
- 拆分某些镜头
- 调整镜头名称
- 直接确认开始生成

### Phase 2: 生成镜头提示词

每个镜头生成一个独立的 `.md` 文件，包含以下三段结构。

**资源使用指令**：生成各段落时，可查阅以下参考文件获取精确术语：
- 查阅 `../video-prompt-director/styles.md` 获取风格参数
- 查阅 `../video-prompt-director/glossary.md` 获取 CG/VFX 术语

## 镜头提示词输出格式

每个镜头文件必须严格包含以下三段结构：

### 第一段：基础设定

#### 角色设定

从源文件的 Section 2（角色与道具）中，提取**本镜头中实际出场**的角色，重新组织为紧凑的角色描述格式：

```
[角色名]：[一句话概括角色类型和核心视觉特征]。
外观：[体型/比例/材质/色彩/标志性特征的精简描述，保留 hex 色号和关键数值参数]。
本镜头状态：[该角色在本镜头中的具体状态（常态/变化态/极端态），描述当前表情、姿态、动作的起始状态]。
```

- 未在本镜头出场的角色不写入
- 道具仅在「画面内容」中提及，不在角色设定中单独列出（除非道具是本镜头的核心视觉焦点）
- 保留源文件中的 `[@图片N]` 图片引用标记（如果有的话）

#### 场景设定

从源文件的 Section 3（环境与场景）中，提取**本镜头可见的环境元素**：

```
场景：[地点描述，建筑风格，年代感]。[可见的具体物品陈设]。
光影：[光源类型、方向、色温]。[特殊光影效果，如丁达尔效应/体积光/焦散等]。
空气：[颗粒物/烟雾/雾气描述，含数量和视觉表现]。
```

- 只描述本镜头画面中实际可见的环境元素
- 如果本镜头的色温与开场不同，必须注明当前色温值

#### 声音设定

从源文件的 Section 3 和 Section 6 的音效描述中，提取**本镜头时间范围内**的声音：

```
声音：[本镜头的完整声音设计，包括：环境底噪 + 角色行动声 + 特效声 + 音量描述]。
```

- 如果源文件注明"不需要配乐，仅保留同期声"，则如实写入
- 保留具体的分贝值和频率参数（如果有）

---

### 第二段：氛围与画质规范

#### 风格核心

从源文件的 Section 1 中提取，用关键词组合表示：

```
风格核心：[关键词1]，[关键词2]，[关键词3]，[关键词4]，[关键词5]。
```

示例：`风格核心：原子朋克，末日丧尸，电影级质感，超写实，极致逼真，真人实景拍摄，杜绝游戏CG感。`

#### 视觉基调

```
视觉基调：[画幅比例]，[摄影机/镜头型号]，[胶片模拟]，[核心视觉质感关键词]。
```

示例：`视觉基调：变形宽银幕电影质感，使用 IMAX 胶片摄影机，搭配 Panavision C 系列镜头（添加动态模糊）拍摄。`

#### 色彩与影调

从源文件 Section 1 的色彩基调 + 色温叙事中，提取**本镜头对应时段**的色彩和色温：

```
色彩与影调：[色温值及氛围]，[色调关键词]，[胶片/滤镜质感]，[光照方式]，[光线具体表现]，[明暗关系]，[整体光影氛围关键词]。
```

- 如果本镜头跨越色温转折点，描述转折过程
- 如果本镜头色温与整体不同，强调差异

#### 美学参考

```
美学参考：[参考作品/导演/风格的名称]，[参考的核心美学特征]。[整体氛围关键词]。
```

示例：`美学参考：参考美剧《辐射》美学风格，皮克斯动画人物动作控制，原本闲适的度假场景与恐怖丧尸形成强烈荒诞反差。整体保持窒息、孤寂的末日孤胆英雄既视感。`

---

### 第三段：画面分镜脚本

这是每个镜头文件最核心、差异化的部分。从源文件的 Section 5（运镜设计）和 Section 6（动作时间线）中，提取本镜头的运镜和动作信息，重新组织为分镜脚本格式。

#### 景别

```
景别：[具体景别]，[补充说明]。
```

可用景别术语（参考 `glossary.md` Camera 章节）：
- 极远景 Extreme Wide Shot
- 远景 Wide Shot
- 全景 Full Shot
- 中景 Medium Shot
- 近景 Medium Close-Up
- 特写 Close-Up
- 极特写 Extreme Close-Up
- 微距 Macro

#### 运镜手法

```
运镜手法：[运镜方式]，[具体参数：焦距/光圈/角度/速度/特殊效果]。
```

必须包含的信息：
- 运动方式（Dolly In/Out, Tracking, Crane, Pan, Tilt, Handheld, Steadicam, Whip Pan, Tilt Down/Up 等）
- 镜头参数（焦距、光圈）
- 角度（Eye Level / Low Angle / High Angle / Dutch Angle + 具体角度值）
- 速度控制（Normal / Slow Motion / Time Dilation + 倍率值）
- 焦点控制（Rack Focus 如有，标注起止点）
- 运动方向描述

#### 画面构图

```
构图：[构图方式]，[主体在画面中的位置]，[前景/背景层次]。
```

常见构图方式：
- 三分法构图（Rule of Thirds）
- 对称居中构图
- 引导线构图
- 框架构图
- 对角线构图
- 黄金螺旋构图

描述要点：
- 主体在画面中的具体位置（如"画面右侧三分之一处"）
- 前景和背景的层次关系
- 景深效果（浅景深/中景深/深景深，光圈值）
- 如果有荷兰角，标注角度

#### 画面内容

这是最重要的部分。用流畅的文字描述本镜头中发生的完整动作和视觉内容：

```
画面内容：[本镜头的完整动作描述，按时间顺序从镜头开始到结束，包含以下要素]：
- [角色动作的详细描述：运动轨迹、速度、形变、表情变化]
- [场景互动：与道具/环境的物理交互及反馈]
- [物理特效：毛发/粒子/冲击波/碎屑等视觉特效]
- [焦点变化：如有 Rack Focus，描述焦点转移过程]
- [画面起始状态 → 结束状态的完整过渡]
```

**画面内容写作要求**：

1. **连贯性**：动作描述必须是连续流畅的，不能是碎片化的要点罗列
2. **物理真实感**：每个动作必须符合物理规律，包含速度、方向、形变参数
3. **视觉具体性**：读者读完这段文字后能在脑中"看到"完整画面
4. **保留量化参数**：从源文件继承所有具体数值（hex 色号、尺寸、帧数、延迟时间、速度倍率等）
5. **慢动作处理**：如果本镜头包含签名镜头的慢动作，画面内容分为两层：
   - 先描述正常速度的完整动作
   - 再用"慢动作展开："开头，描述 Time Dilation 下的视觉奇观细节
6. **篇幅标准**：画面内容部分不少于 200 字

## 文件组织规范

### 输出目录

拆分后的镜头文件存放在与源文件同级的目录下，目录命名格式：

```
{源文件去掉.md后缀}拆分/
```

示例：
- 源文件：`prompts/cc-猫结者（麻糬）/场景一-厨房遭遇战.md`
- 输出目录：`prompts/cc-猫结者（麻糬）/场景一-厨房遭遇战拆分/`

### 文件命名

每个镜头文件的命名格式：

```
{序号}-{镜头名称}.md
```

- 序号：两位数字，从 01 开始，按时间顺序排列
- 镜头名称：从源文件 Section 6 的节拍名称中提取，使用简短有意义的名称

示例：
```
01-午后静好.md
02-风暴前夜.md
03-惊觉炸毛.md
04-一触即发.md
05-激光追猎.md
06-逃出生天.md
```

### 文件头部元信息

每个镜头文件的开头必须包含：

```
> 来源：[源文件名] | 风格：[风格名称] | 原始时长：[总秒数]秒
> 本镜头时间：[MM:SS-MM:SS] | 预计时长：[秒数]秒 | 情绪标签：[标签]
```

```markdown
## 基础设定

### 角色设定

**狸花公仔「麻糬」**（主角）：Q 版毛绒猫咪公仔，头身比 1:1.2，体长约 18cm。
外观：暖棕狸花纹底色 #8B6914 + 深棕条纹 #3B1E08 + 腹部米白 #FFFDD0，毛绒织物 Stylized PBR 渲染。超大圆眼（瞳孔占面部 35%），虹膜亮琥珀 #FFBF00。左耳尖微折，脖挂金色铃铛项圈（#D4AF37，1.2cm）。
本镜头状态：放松趴卧姿态，瞳孔半闭慵懒椭圆，嘴角微微上扬，全身毛发服帖顺滑。

### 声音设定

声音：极度安静的环境底噪——窗外隐约鸟鸣（30dB）、冰箱低频嗡鸣（40Hz, 25dB）、时钟滴答（1Hz, 20dB）。猫粮颗粒被咀嚼的细微碎裂声（35dB）。

## 氛围与画质规范

### 风格核心

风格核心：Pixar-quality 3D animation，subsurface scattering，exaggerated cartoon proportions，vibrant saturated colors，soft volumetric lighting。

### 视觉基调

视觉基调：1.85:1 宽银幕，Pixar RenderMan Path Tracing + Ambient Occlusion 渲染，多层材质渲染（Multi-layer Material），毛绒表面 Stylized PBR。

### 色彩与影调

色彩与影调：5800K 午后暖日光，高饱和度暖色调，琥珀/青绿互补色（amber/teal complementary）。主色调暖琥珀 #FFBF00，对比色深青绿 #2A9D8F，强调色亮橙红 #FF6B35。午后阳光穿过百叶窗在台面和地面投射明暗交替暖光条纹，光线通透均匀，营造慵懒温馨的午后氛围。

### 美学参考

美学参考：经典 Pixar 动画美学，强调角色表情夸张性和材质渲染真实感。温馨日常场景与即将到来的外星入侵威胁形成叙事反差。

## 画面分镜脚本

### 景别

景别：中景（Medium Shot），腰部以上，以猫公仔为主体，包含台面和猫粮碗的局部环境。

### 运镜手法

运镜手法：Steadicam 缓慢 Dolly In（前推），35mm spherical 镜头，f/2.8 浅景深，eye level 平视。推动速度缓慢稳定，营造舒适宁静的观看节奏。

### 画面构图

构图：三分法构图，猫公仔位于画面中心偏左位置，猫粮碗在前景左下方。前景左下角有窗台绿植叶片（#6B8E23）微微探入画面边缘增加纵深。背景橱柜以上区域呈柔和虚化（f/2.8 圆形散景），冰箱贴和厨具挂钩呈柔和光斑。

### 画面内容

画面内容：午后阳光透过白色百叶窗，在奶油色瓷砖地面上投射出一道道水平暖光条纹，空气中漂浮着金色的尘埃微粒，在光束中缓缓飘动。狸花猫公仔麻糬趴在白色大理石台面上，身体放松前倾趴在猫粮碗旁，前爪微曲收在胸前。头部低垂凑近碗口，下颚缓缓开合，以 1.5 秒/次的频率咀嚼猫粮颗粒，双颊随咀嚼微微鼓起再收缩。身后蓬松的尾巴以 2 秒为周期、15° 摆幅缓缓左右摆动，尾尖偶尔勾起画一个小圆弧。阳光照射在服帖顺滑的毛绒表面，边缘呈现温暖的金色轮廓光。铃铛在脖子上安静垂挂，偶尔随身体微动发出极轻的金属闪光。
```

## 执行检查清单

每个镜头文件生成后，必须通过以下检查：

### 基础设定检查
- [ ] 只包含本镜头实际出场的角色
- [ ] 角色描述包含 hex 色号和关键数值参数
- [ ] 角色状态描述符合本镜头时间段（常态/变化态/极端态）
- [ ] 场景描述只包含本镜头可见的元素
- [ ] 色温值与源文件对应时间段一致
- [ ] 声音设计覆盖本镜头时间范围内的所有声源

### 氛围与画质检查
- [ ] 风格核心关键词与源文件 Section 1 一致
- [ ] 视觉基调包含画幅比和渲染技术
- [ ] 色彩与影调描述了本镜头对应时段的色温状态
- [ ] 美学参考提供了具体的参考作品或风格方向

### 画面分镜检查
- [ ] 景别术语准确（参考 glossary.md Camera 章节）
- [ ] 运镜手法包含镜头参数（焦距/光圈/角度）
- [ ] 构图描述了主体位置和前后景层次
- [ ] 画面内容是连贯的叙事文字（非要点罗列）
- [ ] 画面内容不少于 200 字
