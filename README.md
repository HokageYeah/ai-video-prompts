# AI Video Prompt Director

将你的视频创意转化为好莱坞级别的 AI 视频提示词。

输入一句模糊的想法（比如"一只穿宇航服的狗在火星上跳舞"），输出一份包含精准时间线、CG 渲染术语、专业运镜描述的中英文双语提示词——直接复制粘贴给 Sora / Kling / Runway Gen-3 / Luma 即可生成视频。

## 工作流程

```
你的想法 → 需求采集 → 风格选择 → 六段式双语提示词
```

**需求采集**：确认核心剧情、角色设定、环境光影、视频时长。缺失信息会主动提问，不猜测。

**风格选择**：从五种预设风格中挑选，或自定义：

| 序号 | 风格 | 关键词 |
|------|------|--------|
| 1 | 迪士尼/皮克斯 3D 动画 | 高饱和度、夸张卡通比例、次表面散射 |
| 2 | 60 年代原子朋克 (Atompunk) | 复古未来、做旧质感、胶片颗粒 |
| 3 | 赛博朋克/霓虹暗黑 (Cyberpunk) | 霓虹灯反射、体积雾霾、变形宽银幕 |
| 4 | 极致写实自然纪录片 (BBC Earth) | 8K 超高清、微距长焦、自然光影 |
| 5 | 宫崎骏式手绘动画 (Studio Ghibli) | 赛璐璐平涂、水彩背景、温暖色彩 |

**提示词生成**：输出中文解析版 + 英文终极版，严格按六段结构组织。

## 提示词六段结构

每份提示词包含以下六个段落，中英文各一份：

1. **Visual Style & Rendering** — 美学风格、镜头类型、渲染技术、光影氛围、色彩基调
2. **Characters & Props** — 体型/面部/表情/服装材质/道具材质的 CG 级描述
3. **Environment & Scene** — 背景环境/地面材质/天气/空气颗粒/景深虚化
4. **Physics & VFX** — 流体动力学/重力/碰撞反馈/毛发体积物理
5. **Camera Work** — 运镜方式（Dolly / Tracking / Crane / 手持等）
6. **Action Timeline** — `[00:00-00:03]` 时间戳逐秒拆解动作/微表情/场景互动

## 支持的 AI 视频平台

| 平台 | 提示词侧重点 |
|------|-------------|
| Sora | 物理一致性和长镜头连贯性 |
| Kling | 角色表情细节和动作流畅度 |
| Runway Gen-3 | 运镜控制和风格化表现 |
| Luma | 3D 空间感和光影质量 |

未指定平台时默认生成通用高质量描述。

在 [Claude Code](https://claude.ai/code) 中打开本项目，输入 `/video-prompt` 或直接描述你的视频创意即可。
